# 🐍 웹 크롤링을 이용한 영어단어 퀴즈
> **해외 뉴스 기사와 네이버 사전을 연동한 지능형 단어 학습 도구**
> 프로젝트 기간: 2023.08.30 ~ 2023.09.01 (개인 프로젝트)

## 📄 프로젝트 요약
- **기사 추출**: 해외 뉴스 사이트 기사를 실시간으로 크롤링하여 학습 데이터 확보
- **뜻 매칭**: 네이버 사전 API(GET 방식)를 분석하여 뉴스 기사 단어와 정확한 뜻 매칭
- **데이터 자동화**: 크롤링된 데이터를 CSV 형식으로 저장하여 재사용 가능한 데이터베이스 구축
- **학습 앱**: 저장된 CSV 데이터를 바탕으로 Python TK(GUI)를 활용한 퀴즈 게임 구현

---

## 🛠️ 사용 기술 및 라이브러리
- **Language**: Python
- **Libraries**: BeautifulSoup (뉴스 크롤링), Requests & JSON (사전 데이터 파싱), TKinter (GUI 구현), CSV

## 💡 깨달은 점
- **크롤링의 유연성**: 정적인 HTML은 **BeautifulSoup**로, 동적인 데이터나 API 형태는 **GET 방식과 JSON 파싱**을 적재적소에 활용하는 법을 익혔습니다.
- **GUI 프로그래밍**: Python **TKinter**를 사용하여 사용자 친화적인 인터페이스를 구성하고 이벤트를 처리하는 경험을 했습니다.
- **데이터 영속성**: **CSV** 파일을 매개체로 크롤러와 퀴즈 프로그램 간의 데이터를 안정적으로 주고받는 구조를 설계했습니다.
